Understand your gear & stats.

Equipment options, six base stats and upgrade decisions.

01 / READ YOUR LOOT

What to check on equipment

Teaching example · not a real drop or a recommended build

01 / GRADE / COLOR

Unique

Rarity is a category, not a complete verdict. Compare items for the same slot and purpose.

02 / ITEM LEVEL

Item level ≠ character level

Item level describes the equipment. Equip requirements and dungeon entry requirements are separate checks.

03 / MAIN STAT

Weapon attack / armor defense

Start with the item’s main function. Then check whether an upgrade improves the problem you are trying to solve.

04 / EXTRA OPTIONS

Accuracy · critical hit · …

Read each option. A higher score does not tell you whether the option helps your current build.

05 / ENHANCEMENT

+N

The plus number is investment on this item. Compare the cost, success chance and likely replacement before spending.

02 / SIX BASE STATS

Familiar names. Different jobs.

MIGHT →

Attack

Helps attacks hit harder.

DEXTERITY →

Evasion · block · critical resistance

A defensive stat, not an automatic ranged-damage stat.

INTELLIGENCE →

Status effect chance

Helps control effects land. It is not the magic-damage stat.

CONSTITUTION →

Maximum HP

Builds your health pool. Survival also depends on mitigation and mechanics.

PRECISION →

Accuracy · critical hit

Helps attacks connect and critically hit.

WILLPOWER →

Status effect resistance

Helps resist control effects; it does not make every boss mechanic avoidable.

03 / UPGRADE OR WAIT?

Make the cost solve a problem.

01

Find the bottleneck

Entry score, survival, accuracy or damage? Name the problem first.

02

Read the upgrade screen

Check the item type, success chance and exact materials. Ordinary gear and Clash Runes have different failure rules.

03

Set a stopping point

Decide how much to spend before clicking. Recheck the benefit after the upgrade.

What happens if enhancement fails?

The Global reference lists material loss without an enhancement-level drop for ordinary weapons, armor and accessories. Clash Runes are an exception and can lose a level. Always read the confirmation for your item type.

Arcana is equipment, not a skill.

KR guides may call an Arcana piece 천칭 (literally “scales”). This is an equipment name, not a button in your rotation. Use the item tooltip to identify the piece; we do not treat this literal translation as a verified Global item name.
