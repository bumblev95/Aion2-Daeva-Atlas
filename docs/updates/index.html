      [Notice] Patch Notes | Oct. 6 (PDT) / Oct. 7 (CEST)

      Founder’s items can be claimed for other characters and servers. Wing morphing gets a weekly limit, leather drops increase, and map-pin and mission bugs are fixed.

      • System
        Founder’s items

        Eligible owners can claim missing items for free through the tier-specific Shop on other characters and servers.

      • Adjustment
        Wing morphing

        Sealed Wings → Enhance Stones: maximum 20 morphs per server per week.

      • System
        Raw Leather

        Drop rates rise in Chaotic Lower Reshanta, Verteron and Altgard; no percentage is given.

      • System
        Resurrection Spiritstone · Season 1

        Shop price: 25,000 Kina; maximum 10 per server per week.

      • Bug fix
        Map pins / Asmodian mission

        Pins correctly show a maximum of 30. The affected Asmodian weekly mission can complete normally.

      No class-specific balance changes listed in this reviewed patch.

        [안내] 10/7(수) 업데이트 노트 (수정 10/8 11:14)

        Aerial-hit and Sorcerer effect bugs were fixed. Keyed Hidden Cube rewards increased, and presets expanded. These are Korea changes; no class damage percentage was announced.

        • Bug fix
          All classes · aerial hits

          In-range aerial attacks now avoid the intermittent missing-hit bug.

        • Bug fix
          Sorcerer · Fire Wall / Cold Storm

          Height-related ember and frostbite damage failures were corrected; ember damage now uses the Fire element. No increase percentage is specified.

        • Bug fix
          Sorcerer · Hibernation

          The backward movement on release was repaired.

        • Bug fix
          Spiritmaster · summoned spirits

          One Fire Temple trial boss skill no longer deals excessive damage to spirits.

        • System
          Keyed Hidden Cubes

          Soul Crystal reward: 100 → 1,000. Qualifying Chapter 1 claims receive a retroactive difference.

        • System
          Presets

          Main presets: 3 → 5. Wardrobe presets: 3 → 6.
