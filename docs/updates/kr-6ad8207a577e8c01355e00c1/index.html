    Noble Crystal Arcana · extraction unavailable

    After the third-week October KR update, attempting extraction displays an invalid Arcana extraction-data system message and does not complete. The notice reports investigation and response in progress, not a completed fix.

    Combat impact P1 analysis: the October 21 KR guidance to extract excess Arcana may currently fail for this named item. Do not infer that every Arcana type is affected or that items are deleted.
