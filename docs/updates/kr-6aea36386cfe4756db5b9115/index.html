PATCH NOTES / KR

November 4 · Korea

KR moves every Abyss Outland entry window 10 minutes later and adjusts its opening, poison, wind-route and consumable rules. It also adds standard color codes, Soulstone chain use and an autumn pass, while fixing Deltras Shock Release and Outland Flame Bomb damage behavior.

CLASS CHANGES

All classes ↔ Adjustment

Adjustment 3 · Bug fix 2 · Other change 3

  • ↔ Adjustment

    Abyss Outland · entry windows

    Every announced daily entry window moves 10 minutes later while keeping the 30-minute opening interval.

    Before11:00–13:30 and 20:00–23:30→After11:10–13:40 and 20:10–23:40

    Combat impact P0 analysis: the existing public first-entry guide would send players to obsolete slots, so its schedule must change immediately. Registration cutoffs and the final eligible slot still need client verification.

  • ↔ Adjustment

    Abyss Outland · opening and poison phases

    The airship now disappears when the barrier drops after the match begins, upper-floor poison appears 30 seconds later, the middle-floor wind route moves, and stage-3 poison on every floor is normalized to the same damage.

    Combat impact P1 analysis: opening positioning, upper-floor timing, middle-floor routing and late-poison survival plans may change. Exact coordinates, trigger times, damage and counterplay remain direct-verification items.

  • ↔ Adjustment

    Abyss Outland · stealth and invincibility potions

    Using an attack skill while hidden by a stealth potion now breaks stealth. Invincibility-potion duration is reduced, but movement and skill use become possible while invincible.

    Combat impact P1 analysis: stealth openers and invincibility routing need re-testing. NC publishes no old/new invincibility duration, so no uptime or damage percentage is invented.

  • • Other change

    Standard color-code input

    A standard color-code field is added to customization, Wardrobe and Settings > Chat Text Color. The prior code format remains available in a legacy field.

    Combat impact P2 analysis: this is a UI/convenience change. Confirm accepted formats, validation behavior and saved presets before publishing exact input examples.

  • • Other change

    Autumn login reward and event pass

    From November 4 maintenance to November 11 maintenance, KR adds a seven-day login reward. A level-10+ event pass is also sold once per server for 100,000 Kinah per track, runs to November 11 at 05:00, has 30 levels and up to 10 repeat rewards.

    Combat impact P1 analysis: this creates a temporary daily/growth route. Mission credit, server purchase scope, premium activation, reward claims and deletion of event currency need client verification; the full event table is outside this highlights review.

  • • Other change

    Consecutive Soulstone use

    An auto-use setting can continue through Soulstones of the same grade, consuming untradeable items before tradeable ones. It does not switch grades automatically.

    Combat impact P2 analysis: beginner settings guidance can point to the official menu, but inventory order, toggle persistence and interruption behavior remain direct-verification items.

  • ✓ Bug fix

    Deltras · Frozen Bind and Shock Release

    Fixes a condition where a target caught by Frozen Bind during Deltras could use Shock Release and then move or use skills.

    Combat impact P1 analysis: the KR Snowfield guide must no longer imply Shock Release is a reliable escape. The exact condition, immunity interactions and party rescue response require live reproduction.

  • ✓ Bug fix

    Abyss Outland · Flame Bomb damage

    Fixes Flame Bomb damage being applied incorrectly in Abyss Outland.

    Combat impact P1 analysis: this is a damage-behavior fix without a published value. Do not assign a buff or nerf percentage until before/after damage is reproduced under the same conditions.

PATCH HIGHLIGHTS

Other patch highlights

01Region, announcement and effective date

  • Published November 3 at 19:30 UTC for the Korean service and scheduled to apply with November 4 maintenance. This review is bound to official source hash cebda46d….
  • KR-only: none of the Outland timings, boss fixes, event costs or settings are copied to North America. No class coefficient, cooldown, skill-level effect or measured DPS result is announced.

02Outland schedule and combat rules

  • Official fact: both entry windows move exactly 10 minutes later to 11:10–13:40 and 20:10–23:40, every 30 minutes. P0 public target: /guides/abyss-outland/ and /ko/guides/abyss-outland/; source target: outland.py.
  • Official fact: barrier/airship timing, upper poison delay, middle wind-route position, stage-3 poison damage, stealth break and invincibility behavior change. P1: update the dated preparation guide with announced facts, while leaving exact coordinates, values and tactics marked unverified.

03Boss and damage fixes

  • Deltras no longer allows the published Frozen Bind/Shock Release bypass. P1 public target: /guides/kr-bitan/ and /ko/guides/kr-bitan/; source target: advancedguides.py. Confirm the trigger, CC immunity, skill availability and party rescue flow in game.
  • Flame Bomb damage is corrected without before/after numbers. Keep data/skills.json, data/skill-snapshot.json, eDPS inputs and historical rankings unchanged.

04Growth, settings and temporary events

  • The login reward and autumn pass are temporary KR growth routes. P1 targets after verification: /routines/, /endgame/ and Korean counterparts; source targets routines.py and progression.py. Verify unlock, mission credit, costs, server scope, claims and expiry before adding evergreen priorities.
  • Standard color codes and Consecutive Soulstone Use are P2 settings targets for /start/?view=settings and /ko/start/?view=settings, with source onboarding.py. The current patch review records the exact menu and behavior; UI persistence and input validation remain unverified.

05Review limits

  • This highlights review covers Outland, the boss fix and progression-relevant systems. It does not claim complete republication of every event reward row or product table, in-game validation or a final class tier.
