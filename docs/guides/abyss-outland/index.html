Abyss Outland: first-entry guide · Korea

Check eligibility, KR server times and weekly rewards before your first solo PvP survival match.

KR ONLY · 2026-10-28

Meet both level requirements, then check an opening in the KR client. This English page describes Korea only; it does not announce availability on other servers.

What am I trying to do?

A solo PvP survival contest: the official notice describes about 100 players competing until one remains. Ranking follows survival order. Surviving longer is the stated objective; this is not a dungeon boss clear.

Your first-entry checklist

  1. Check both numbers

    Check character Lv45+ and item level 3,000+. Meeting only one is insufficient. Item level is not Combat Power.

  2. Choose a daily window

    Use the KR schedule below. Before setting aside time, check the current client notice for maintenance or changes.

  3. Check entry through the Abyss UI

    The official entry route is the Abyss UI. Read the Outland entry information shown there. Exact tabs, button names, queue opening time and confirmation steps are unverified; follow the current client instructions.

  4. Prepare for a learning run

    Editorial checklist: review familiar movement and defensive skill controls before joining. Read any displayed match rules. No mandatory gear, consumable, PvP build or winning tactic is established by this guide.

  5. Compare placement and reward

    Check the result and actual coin award, then the remaining weekly earning allowance and exchange-shop prices. The result-screen layout and manual versus automatic reward delivery are unverified.

When can I participate?

  • 11:00–13:30
  • 20:00–23:30

Daily, every 30 minutes within the announced windows, on the KR server schedule. These are not your device’s local times. The interval does not establish a 30-minute match duration. Exact registration deadlines and final-slot admission need client verification.

What do I earn, and when does the cap reset?

Survival placement → Traveler’s Coins (방랑자의 주화) → items in the Abyss exchange shop. The English coin name here is a guide translation, not a verified Global-client label.

There is a weekly earning cap, reset every Wednesday at 05:00 on the KR server schedule. This resets the earning limit; the notice does not say that held coins expire. Rank payouts, the cap amount, item prices and character/account scope remain unverified.

Before spending, compare the actual shop price with your coin balance. No guaranteed weekly income or recommended purchase order is calculated here.

In-game verification still needed

  • Matchmaking, exact player count, match duration and tie handling
  • UI buttons, queue deadlines and reward-claim controls
  • Rank payouts, weekly cap amount, shop stock/prices and cap scope

If entry is unavailable, recheck both requirements, the current KR time and any displayed restriction. Do not assume a hidden quest or a particular button sequence.
