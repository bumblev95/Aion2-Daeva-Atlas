수치로 비교하세요.

eDPS는 이동·무적 시간을 포함한 전체 전투 시간으로 계산합니다. 피해량과 쿨타임을 바꾸면 패치 전후 차이를 바로 보여줍니다.

초기값은 글로벌 기본 1레벨 툴팁 중 직접 피해 항목입니다. 동작 시간 1초는 수정 가능한 가정입니다. 최종빌드·현재 직업 티어를 검증한 수치는 아닙니다.

현재 패치 확인 중…

언제 사용할 수 있는 스킬인가요?

Burst Arrow는 둔화 또는 속박, Condemnation은 고통의 연쇄, Blaze는 불의 표식이 필요합니다. Judgment와 Dark Crush에는 선행 기술이 필요합니다. 빠진 조건을 항상 활성 상태로 가정하지 않습니다.

선행 효과는 동작 완료에 생성되고 다음 기술 시작에 검사합니다. 종료 시각부터는 사용할 수 없습니다. 확률 적중·발동, 미확인 연계 시간, 한국판 효과는 확인한 구간을 입력하세요. 불의 표식의 20% 추가 피해 발동은 별도 효과이며 미반영입니다. 고통의 연쇄의 10초 지속 피해를 검증된 Condemnation 사용 구간으로 대신하지 않습니다.

확인한 상태·연계 구간 입력

전투 시작 기준 초 단위입니다. 예: 0-5, 20-25. 빈칸은 확인한 구간이 없다는 뜻입니다. 면역 대상 발동 구간은 해당 기술이 실제로 사용 가능해진 경우에만 입력하세요. 툴팁의 발동률만으로 구간을 만들지 않습니다.

MP 자원 계산·정령 원소 중첩

MP는 기술 시작에 소모하고 완료에 회복하며 공격 불가 구간에도 자연 회복합니다. 스킬의 빈 MP 소모 칸은 미검증이며 MP 계산을 켜면 해당 스킬을 막습니다. 원문의 대시를 소모량 0으로 해석하지 않습니다. Elemental Fusion에는 원소 4중첩이 필요하며 사용 시 4개를 소모합니다. 정령 공격 빈도는 추정하지 않습니다. 스태미나 소모는 미검증이며 문양 피해에는 명시한 소모 가정이 필요합니다. 이 값들은 입력 조건이며 실측 스탯이 아닙니다.

직업별 조건 조사·출처
지속 피해·문양·대상 입력

확인된 피해 수치와 미확인 시간 규칙을 구분합니다. 기본값은 지속 피해와 문양 배율을 제외합니다. 시험할 가정을 직접 선택하세요. 선택한 가정은 실제 게임 검증 결과가 아닙니다.

스킬 행에서 틱 피해·간격·지속·첫 틱 시점을 수정합니다. 공격 불가 구간에도 시간은 흐르며 그 구간의 틱과 전투 종료 이후 틱은 피해에서 제외합니다. 적중률 100% 미만에서는 실제 적용 시간축이 필요하므로 지속 피해·문양 자동 적용을 막습니다. 맹수의 포효는 10초 문양 1개를 제공하며 모델은 5중첩 한도와 각 중첩의 개별 만료를 가정합니다. 갱신·소모 방식은 미검증입니다. NPC 발동률도 면역을 무시하지 않습니다.

스킬 입력과 사용 우선순위

위쪽 스킬부터 사용 가능한 기술을 선택합니다. 직접 피해와 지속 피해 틱은 따로 계산합니다. 측정한 시간을 입력하세요. 소환·덫 발동·차징 시간에는 직접 입력이 필요합니다. 쿨타임은 동작 시작부터 계산하며 공격 불가 구간에 걸친 동작은 생략합니다.

확인된 직접 피해를 유지합니다. 미확인 차징·소환·덫은 피해·시간 입력을 확인하기 전까지 사용하지 않습니다.

같은 조건의 빌드 비교

빌드를 두 개 이상 추가하세요. 지역·패치·전투 시간·공격력·치명·적중·배율·공격 불가 구간·대상 상태이상 설정·선행 구간·자원 조건이 같아야 순위를 표시합니다. 입력한 모델의 순위이며 전체 서버 실측 순위는 아닙니다.

비교는 이 브라우저에 저장합니다. 패치 후 저장 빌드를 불러와 수정하고, 별도 사본은 CSV로 내려받을 수 있습니다.

계산식·가정·미반영 항목

기대 피해 = (고정 피해 + 공격력 × 계수) × 타격 수 × (1 + 치명 확률 × (치명 배율 − 1)) × 적중 확률 × 사용자 배율

eDPS = 전체 기대 피해 / 전체 전투 시간

게임의 방어·증폭 합연산·발동 피해·쿨 초기화·버프 피해·타격별 치명 규칙·스킬 레벨 상승은 추정하지 않습니다. 지속 피해의 첫 틱·치명·갱신 규칙과 문양 소모는 명시적인 입력 가정입니다. 확인한 선행 조건과 선택한 MP 제한은 기대 피해 계산과 별도로 검사합니다. 확인한 효과만 입력에 반영하고 중복 계산을 피하세요. 변경 피해 %는 해당 스킬의 입력 피해만 바꾸며 직업 전체 배율이 아닙니다.

최종빌드 티어에는 같은 패치의 스킬 레벨·특화·아르카나·데바니온·장비·사이클 시간·반복 측정 자료가 직업별로 필요합니다. 현재 이 자료는 미완성입니다.
