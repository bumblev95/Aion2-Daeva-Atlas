엔드게임 공략.

스토리 이후 봉인 던전·깃털·모노리스 보상을 스킬 포인트·데바니온·장비 성장으로 연결하는 순서.

초반 공략 →엔드게임 공략
스토리 이후 성장

메인 스토리 이후, 강해지는 순서 5단계

남은 포인트와 놓친 필드 보상부터 챙긴 뒤, 필요한 장비를 얻을 수 있는 던전을 반복합니다.

글로벌 아이템 자료와 한국 필드 공략을 구분했습니다. 획득 수량·해금 조건은 현재 서버의 보상 화면에 맞춰 확인합니다.

  1. 01

    이미 받은 포인트부터 실제 성장으로 바꾸기

    가방에 남은 지혜의 돌·데바니온 결정을 사용하세요. 스킬 포인트는 자주 쓰는 기술에 투자하고, 열린 특화 슬롯에 효과를 장착합니다. 데바니온 포인트는 필요한 능력치·스킬 노드에 배분합니다.

    성장 확인 투자 전후의 스킬 레벨·장착한 특화·데바니온 노드를 확인합니다.

    직업별 스킬 투자 순서 →
  2. 02

    지도에서 놓친 봉인 던전·지역 보상 챙기기

    지도에 ?가 보이면 이름을 열어 지역 퀘스트인지, 봉인 던전인지, 다른 콘텐츠인지 구분하세요. 가까운 미완료 봉인 던전부터 실제 보상 목록을 확인해 완료 보상을 받습니다. 지혜의 돌·데바니온 결정을 얻었다면 사용하고 각각의 포인트를 투자합니다.

    성장 확인 클리어 → 완료 보상 받기 → 아이템 사용 → 포인트 투자까지 이어져야 합니다.

    천족 봉인 던전 위치 →마족 봉인 던전 위치 →
  3. 03

    깃털을 줍고 모노리스에서 보상으로 교환하기

    깃털 모양의 주신의 흔적은 한국 공략에서 모노리스 공명으로 연결됩니다. 모노리스에 반납해 보상을 받고, 지혜의 돌은 사용하고 계시의 아뮬렛 강화 주문서는 해당 아뮬렛에 씁니다. 활성화한 이동 거점 근처부터 작은 구역씩 정리하세요.

    성장 확인 깃털 수집 → 모노리스 반납 → 보상 사용·아뮬렛 강화가 한 묶음입니다.

    깃털 위치·원문 공략 →
  4. 04

    장신구 성장도 한 부위씩 마무리하기

    한국 필드 공략은 주둔지 보상을 고결의 허리띠 강화 주문서·마석으로 연결합니다. 현재 서버에서도 같은 보상이 보이면 해당 허리띠와 필요한 장비 옵션에 활용하세요. 재료만 모아두기보다 한 부위의 강화 전후를 확인합니다.

    성장 확인 스킬·데바니온 성장, 장신구 강화, 새 장비 획득은 서로 다른 성장 경로입니다.

    장비·강화 안내 →
  5. 05

    보상 받을 수 있는 던전부터 반복하고 다음 단계로 이동하기

    지금 열려 있는 콘텐츠 중 필요한 보상이 있는 곳을 고릅니다. 원정은 장비, 초월은 아르카나 성장으로 연결하고, 사명 등 해금된 콘텐츠에서 다음 강화에 필요한 재화를 확보합니다. 반복하기 전에 남은 보상 횟수와 오드 에너지 등 보상 조건을 확인하세요.

    성장 확인 성장 후 다음 난이도 입장 조건과 클리어 안정성을 다시 확인하고 목표를 올립니다.

먼저 정리할 완료 보상

미완료 지역 콘텐츠, 깃털 수집, 가방에 남은 성장 보상부터 정리합니다. 완료한 필드 콘텐츠를 다시 돈다고 첫 완료 보상이 계속 생기는 것은 아닙니다.

이후 반복할 보상 파밍

필요한 보상이 있는 해금된 던전·사명 등을 반복합니다. 입장 가능 여부와 보상 횟수를 따로 확인하고 성장 목표 하나를 마친 뒤 다음 목표를 정합니다.

획득 → 보상 수령 → 아이템 사용 → 투자·장착 → 다음 콘텐츠 확인까지 이어가세요.
