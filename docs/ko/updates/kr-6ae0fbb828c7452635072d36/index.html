10월 28일 한국 패치

한국 10월 28일: 아그로 출현이 하루 두 번의 고정 시각으로 바뀌고, 개인 PvP 생존 콘텐츠 어비스 아웃랜드가 정해진 시간에 열리며, 모든 채집 시도가 서버 단위 일일 제한에 집계됩니다. 최신 수정 원문을 다시 읽었으며 기존 highlights에 새 직업 계수·쿨타임·스킬 레벨 효과나 다른 의미 변경은 확인되지 않았습니다.

2026-10-27 UTC요약 검토 완료원문 수정: 2026-10-28 01:57 UTC
NC · 공식 원문 ↗

직업 변경과 주요 시스템 내용을 검토해 요약했습니다. 이벤트 보상·상품 전체 표는 공식 공지에서 확인하세요. 직업 표시는 공지된 변경을 분류합니다. 실전 영향은 효과를 설명한 분석이며 전체 DPS 실측 상승률이 아닙니다. 한 직업이 버프와 너프를 함께 받으면 ‘조정’으로 표시합니다.

    정령왕 아그로 · 출현 시각

    혼돈의 에레슈란타 하층 아그로가 서버 오픈 기준 12시간 주기에서 매일 고정 시각 출현으로 변경됩니다. 정기점검 직후에는 등장하지 않습니다.

    변경 전서버 오픈 시 등장 후 12시간마다→변경 후한국 서버 일정 기준 매일 09:00·21:00

    실전 영향 P1 해석: 고정 시각에 맞춰 보스 참여 계획이 달라집니다. 패턴·난도·HP·보상 변경은 공지되지 않았으며 실제 한국 서버 시계와 점검 후 첫 출현은 직접 확인해야 합니다.

  • • 기타 변경

    어비스 아웃랜드 · 개인 PvP 생존전

    어비스 UI에서 약 100명이 참여해 최후의 1인을 가리는 배틀 로얄 형태의 개인 PvP 콘텐츠가 정해진 시간에 열립니다. 생존 순서로 순위를 정하고 방랑자의 주화를 지급하며, 주간 획득 한도는 수요일 05:00에 초기화됩니다.

    실전 영향 P1 해석: 한국 PvP와 주간 재화 획득 경로가 추가됩니다. 매칭 방식·실제 인원·경기 시간·동순위 판정·주화 수량·획득 한도·상점 비용은 직접 검증해야 합니다.

  • • 기타 변경

    채집 · 일일 시도 제한

    일일 채집 제한이 도입됩니다. 성공·실패·취소를 포함한 모든 시도가 서버 단위로 집계되고 매일 05:00에 초기화되며 현재 횟수는 HUD 좌측 상단에 표시됩니다. NC는 정확한 제한 횟수를 공개하지 않았습니다.

    실전 영향 P1 해석: 제한 수치와 적용 범위를 확인한 뒤 파밍 동선에 시도 횟수 관리가 필요합니다. 이 공지만으로 기존 지도 좌표나 출현 정보가 바뀌지는 않습니다.

  • ✓ 버그 수정

    심연의 재련: 루드라 · 중간 보스 파티 위치

    중간 보스 전투 중 캐릭터가 소속 파티에 맞는 위치에 있지 않으면 던전 입구로 이동하도록 수정됩니다.

    실전 영향 P1 해석: 잘못된 파티 인스턴스·위치에서 전투에 참여하는 상황을 막을 수 있습니다. 발동 조건·파티 재배정·재입장 흐름은 직접 확인해야 하며 보스 패턴·피해 변경은 공지되지 않았습니다.

  • ✓ 버그 수정

    모바일 회피 서포트 · 필수 장판

    모바일 회피 서포트가 플레이어가 밟아야 하는 장판까지 피하던 현상을 개선합니다.

    실전 영향 P2 해석: 모바일 기믹 수행 안정성이 좋아질 수 있지만 대상 전투·발동 조건은 공개되지 않았습니다. 공략 문구를 바꾸기 전 필수 장판 동작을 재현해야 합니다.

  • ✓ 버그 수정

    비전투 지속 피해 · 질주·탑승

    비전투 상태에서 지속 피해 효과 때문에 질주·탑승이 해제되던 현상을 수정합니다.

    실전 영향 P2 해석: 전투 후 이동이 끊기는 현상이 줄어듭니다. 피해 계수나 생존 능력치 변경은 아닙니다.

  • • 기타 변경

    아르카나 추출 진행도 복구

    10월 21일 아르카나 추출 항목 변경으로 누적 추출 진행도가 삭제된 캐릭터에게 신비로운 결정(각인) 1개가 일괄 지급됩니다.

    실전 영향 P1 해석: 한국 대상 캐릭터의 고정 복구 지급이며 새 추출 환산율이 아닙니다. 대상 판정·지급 방식·수령 여부는 직접 확인해야 합니다.

주요 시스템·이벤트 변경

01지역·발표일·시행일

  • 10월 27일 19:30 UTC(한국 10월 28일 04:30)에 게시되고 10월 28일 01:57:43 UTC에 수정됐습니다. 최신 본문을 다시 읽고 이번 검토를 원문 해시 26961edb…에 다시 연결했습니다. 읽을 수 있는 게임 변경 사실은 이전 추출 내용과 같고 현재 원문에는 공식 어비스 가이드북 링크가 있습니다. 이전 전체 마크업은 보관하지 않아 표시 요소만의 완전한 전후 비교는 주장하지 않습니다.
  • 한국 전용입니다. 아그로 일정·아웃랜드 규칙·채집 제한·루드라 수정·복구 지급을 북미에 적용하지 않습니다. 직업 계수·쿨타임·스킬 레벨 효과·실측 DPS 결과는 공지되지 않았습니다.

02어비스 보스 일정·아웃랜드

  • 공식 확인: 아그로는 서버 오픈 기준 12시간 주기에서 매일 09:00·21:00 출현으로 바뀌며 점검 직후에는 등장하지 않습니다. 패턴·HP·충돌 판정·난도·보상 변경은 공지되지 않았습니다.
  • 공식 확인: 어비스 아웃랜드는 약 100명이 참여하는 시간제 개인 PvP 생존 콘텐츠이며 캐릭터 45레벨·아이템 레벨 3000이 필요합니다. 공지된 두 일일 시간대에 30분 단위로 열리고 생존 순위에 따라 주간 한도가 있는 방랑자의 주화를 지급합니다.
  • P1 검증 후 보강 경로: 양 언어의 /guides/pvp-context/·/routines/, 소스는 content.py·routines.py입니다. 현재 main에는 어비스 보스 타이머·아웃랜드 전용 공략이 없어 경로·전투법·애니메이션을 추정해 만들지 않습니다. 서버 시계·점검 후 첫 출현, 매칭·경기 규칙·순위·주화 수량/한도·상점 품목·초기화를 확인해야 합니다.

03채집 제한·지도 영향

  • 공식 확인: 성공·실패·취소를 포함한 모든 채집 시도가 서버 단위 일일 제한에 집계되고 05:00에 초기화되며 HUD 좌측 상단에 표시됩니다. 제한 수치와 '서버 단위'가 캐릭터·계정 중 어느 범위인지 명시하지 않아 추정하지 않습니다.
  • P1 검증 후 보강 경로: /maps/·/ko/maps/, data/maps.json, resourcemap.py, worldmap.py입니다. 공지는 시도 집계만 바꾸므로 좌표·스폰 위치·획득 조건·재료 사용처는 유지합니다. 파밍 우선순위 안내 전 제한 수치, 캐릭터/계정/서버 범위, HUD 카운터, 실패·취소 집계, 05:00 초기화를 확인해야 합니다.

04루드라·모바일 지원·복구

  • 루드라 중간 보스 수정은 소속 파티에 맞는 위치가 아닌 캐릭터를 입구로 이동시킵니다. 현재 main에는 한국 루드라 전용 경로가 없어 정확한 전투·발동 조건·파티 재배정·재입장 흐름을 재현할 때까지 /updates/kr-6ae0fbb828c7452635072d36/와 /ko/ 대응 페이지에 사실을 유지합니다.
  • 모바일 회피 서포트는 필수 장판을 피하지 않도록 개선됩니다. 재현 후 P2 경로는 /start/?view=settings·/ko/start/?view=settings입니다. 대상 전투와 장판 발동 조건은 공개되지 않아 보스 애니메이션이나 공통 기믹 규칙은 바꾸지 않습니다.
  • 10월 21일 추출 항목 변경으로 진행도가 삭제된 대상 캐릭터에는 신비로운 결정(각인) 1개가 지급됩니다. P1 검증 경로는 /endgame/·/guides/endgame-crafts/와 advancedguides.py이며 대상 판정·지급·수령과 기존 진행도 문제의 해소 여부를 확인해야 합니다. 추출 환산율 입력값은 아닙니다.

05기타 수정·검토 범위

  • 캐릭터 변경 연출은 밝은 색감에서 어두운 색감으로 바뀌고 PowerVR 모바일 화면 오류가 수정되며 비전투 지속 피해가 질주·탑승을 해제하던 현상이 사라집니다. 전투 계수가 공지된 변경은 아닙니다.
  • 성장 관련 콘텐츠와 주요 수정의 highlights 검토이며 상품·이벤트 전체 재게시가 아닙니다. 인게임 검증이나 최종 직업 티어를 주장하지 않습니다. 정확한 원문 해시 데이터 경로는 data/patch-reviews.json·data/news.json, 검증 대기는 data/coverage-audit.json에 기록합니다. data/skills.json·data/skill-snapshot.json과 과거 DPS·순위는 유지합니다.
