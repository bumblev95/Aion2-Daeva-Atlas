  • P1 경로는 /classes/<class>/·/skills/<skill>/와 한국어 대응 페이지, 소스는 data/skills.json·data/skill-snapshot.json입니다. 툴팁·계수·쿨타임·조건기·충전·동작 시간·재현 가능한 로테이션을 직접 확인해야 합니다.
