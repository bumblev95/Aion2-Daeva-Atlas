공식 공지의 전체 변경 주제와 수치 표를 읽기 쉽게 다시 정리했습니다. 직업 표시는 공지된 변경의 분류이며 전체 DPS 실측 결과를 뜻하지 않습니다. 한 직업이 버프와 너프를 함께 받으면 ‘조정’으로 표시합니다.

콘텐츠부터 오류 수정까지

01업적

  • 필드 네임드의 처치 업적이 미완료일 때 월드맵 보스 아이콘에 배지를 표시합니다. 완료했거나 관련 업적이 없으면 배지를 표시하지 않습니다.

02네임 플레이트

  • 내 네임 플레이트를 숨길 수 있습니다. 정보 출력 → 일반 → 네임 플레이트 → 내 네임 플레이트 표시에서 설정합니다.

03어비스

  • 에레슈란타 표층 입장 후 장비 교체 등으로 허용 스펙을 넘으면 즉시 사망합니다. 추방과 이용 시간 1시간 차감도 계속 적용됩니다.
  • 서버 재매칭으로 아티팩트·회랑 점령 상태를 초기화합니다. 21개 매칭 그룹의 상대 서버와 시작 시간은 아래 표에 담았습니다. 모든 시간은 한국 공지 기준입니다.
  • 에레슈란타 표층·하층·중층과 균열 지대의 대규모 전투 끊김을 줄이는 최적화가 적용됩니다.

04제련석

  • 무스펠의 성배 보통·어려움과 비탄의 설원 전 난이도에서 상위 제련석 확률이 올라갑니다. 원정 교환 상점에 달인의 최상급 제련석(각인)이 추가됩니다.

05어비스 점령전

  • 차원핵의 마지막 일격을 얻지 못한 종족도 보상을 받습니다.

06산들바람 상회

  • 부활의 정령석(각인)·펫 자동 줍기권(각인)의 상회 구매 가격을 내립니다. 자동 줍기권의 NPC 판매 가격도 내립니다. 기존 구매 키나 차액은 로그 확인 후 소급 지급 예정입니다.

07명화의 잔흔

  • 페스타 모드별 잔흔을 슈고 페스타(잔흔: 명화)로 통합합니다. 기존 잔흔도 물질 변환으로 통합 재료로 바꿀 수 있습니다.
  • 원정 잔흔을 강화석·영혼 결정으로 바꾸는 변환식을 추가합니다. 전에 삭제·판매한 대상 아이템은 로그에 따라 복구 예정이며, NPC 판매분은 판매 키나를 먼저 회수합니다.

08사명 퀘스트

  • 베르테론·알트가르드의 사명 퀘스트 보상을 엘테넨·모르헤임 수준으로 맞춥니다.

09상점 상품 추가 및 변경

  • 어비스·악몽·페스타 상점에 스티그마 샤드를 추가합니다. 어비스 상점에는 AP 부담을 낮춘 데바니온 결정: 아스펠(각인) 상품을 추가합니다.
  • 페스타 영혼 결정은 50개 묶음으로 주당 최대 15묶음, 악몽 영혼 결정도 50개 묶음으로 바뀝니다.

10일일 던전 보상 조정

  • 낮은 점수 구간의 보상을 늘리고 점수별 보상 차이를 줄입니다.

11히든 큐브

  • 열쇠를 쓴 영혼 결정 보상은 100→1,000개입니다. 챕터1의 해당 수령분도 새 기준의 차액을 로그에 따라 소급 지급할 예정입니다.

12부활의 신호탄

  • 기간: 10월 7일 점검 후~10월 21일 점검 전. 기존 판매분에 추가해 45레벨 이상 캐릭터가 매주 30개까지 구매합니다. 단가 25,000 키나, 상회 특수 탭을 이용합니다.

13원정·초월 한가위 이벤트 종료

  • 관련 이벤트 재료·변환식을 제거하고 보상량을 평시 수준으로 되돌립니다. 히든 큐브 외형도 기존 디자인으로 돌아갑니다.

14개선사항

  • 내 날개 소리를 켜거나 끄는 사운드 옵션을 추가합니다.
  • 장비·날개·타이틀·만신전·종족 이해도·스킬·아르카나 프리셋과 HUD 세트를 3→5개로 늘립니다. 옷장 프리셋은 3→6개입니다.

15수정사항

  • Radeon 8060S의 캐릭터 미표시, FSR 화면 아티팩트, Redmi Note 14의 실행 직후 종료, 일부 Galaxy Fold의 UI 잘림을 해결합니다.
  • 포스 안에서 이동해도 이미 놓은 월드 징표가 계속 보입니다. 정령성 소환 정령에 대한 불의 신전 보스 수정은 직업 카드에도 표시했습니다.
