콘텐츠부터 오류 수정까지

01성역

  • 신규 비탄의 설원은 쉬움·보통·어려움 난이도를 제공합니다. 보스방 진입 후 시작 지점에 보스방 앞으로 가는 포탈도 생성합니다.

02인장

  • 인장 장비 슬롯을 추가합니다. 제작 또는 비탄의 설원 장비 변경권과 키나를 쓰는 물질 변환으로 얻습니다.

03신규 장비

  • 진 창룡왕/멸룡왕 무기·가더 제작과 빛나는 계열의 계승 도안을 추가합니다. 해방된 백야 무기·가더를 변환해 제작 재료를 얻을 수 있습니다.

04원정/성역

  • 분노의 사념·의지·자아·염원·승화·신념·성화의 획득처를 재분배합니다. 크라오·드라웁니르·우루구구·바크론·불의 신전·사나운 뿔·죽은 드라마타·무의 요람은 각인 재료만 나옵니다.
  • 환영의 회랑·푸른 숨의 섬·타락한 데바의 성·잠식된 데우스는 7종 모두 각인·거래 가능 형태가 나옵니다. 무스펠의 성배는 7종의 각인 재료를 제공합니다.

05영혼 결속

  • 현자의 돌: 진리(각인)를 추가합니다. 권능(각인) 10개를 변환해 진리 1개를 만듭니다.

06어비스

  • 서버 재매칭으로 아티팩트와 회랑 소유 상태를 초기화합니다. 매칭 결과는 CM 공지에서 확인하도록 안내됐습니다.

07어비스 균열 지대

  • 보스 능력치를 올리고 전체 보스 수·페이즈 구성을 조정합니다. 8종의 보스는 일정 체력 아래에서 최대 두 번, 25초간 무적이 됩니다.
  • 보스 수 감소에 맞춰 균열 꾸러미 보상을 늘리고 어비스 주간·시즌 미션을 추가합니다.

08차원 침공

  • 입장 아이콘에서 제목·보상 등의 세부 정보를 먼저 보고 입장할 수 있습니다.

09스트리머 모드

  • 기타 → 계정에서 계정 정보 비공개와 내 캐릭터 이름 숨기기를 각각 설정합니다. 이름 숨김은 표시 영역의 이름을 @플레이어로 바꿉니다.

10옷장

  • 패턴 가로·세로를 따로 조정할 수 있습니다. 가로세로 비율 유지 옵션을 켜면 이전처럼 비율을 유지합니다.

11계승 제작

  • 재료 장비의 요구 강화 단계 조건을 충족해야 계승 재료로 등록할 수 있습니다.

12칭찬 시스템

  • 원정·초월·시련·성역의 마지막 보스 후 대상·사유를 골라 클리어당 한 번 칭찬합니다. 팝업 제한 시간 안에 선택하며 완료 후 결과를 봅니다.
  • 칭찬 권한과 후보는 처치 시 파티·던전에 남아 있고 최소 기여도를 채운 파티원입니다. 성역 후보는 당시 자신의 파티로 한정됩니다. 누적 수는 캐릭터 정보에 표시하고 관련 성장·커스텀 업적도 추가합니다.

13성역 명예의 전당

  • 비탄의 설원 어려움 최종 보스의 전 서버 첫 세 클리어를 기록합니다. 기여도 없는 캐릭터는 제외하며 입장 화면 좌상단에서 볼 수 있습니다.
  • 캐릭터·서버·레기온·직업·최고 전투력·최고 아이템 레벨·포스 순번·일자·클리어 시간을 보존합니다. 이후 이름이 바뀌어도 기록은 바뀌지 않습니다.

14시공의 균열 쟁탈전

  • 준비·진행 중 월드맵 쟁탈전 탭과 알리미 아이콘의 해당 지역 바로가기를 제공합니다.
  • 그룹당 주둔지 5→4개, 전투 25→15분입니다. 공격팀은 3개 점령, 방어팀은 3개 이상 보호가 승리 조건입니다. 주둔지 구성은 표에 전부 담았습니다.
  • 참가 중 비행력 소모가 50% 감소합니다. 짧은 시간에 같은 캐릭터 반복 처치 시 기여도를 제한하고, 처치 도움 기여도를 소폭 낮춥니다.

24개선사항

  • 인장 추가로 NPC 판매·창고 간편 등록의 장신구 세부 설정을 초기화합니다. 멤버십은 잔여 30분 이하에 남은 시간을 표시하고 만료 때 메시지를 보냅니다. 미접속 만료는 다음 접속 때 안내합니다.
  • 프리셋별 스킬 레벨을 다르게 설정합니다. 기존 2·3번 프리셋 스킬 레벨을 초기화하며 연계 기술을 선택해도 원본·선행 스킬을 기준으로 레벨 변경할 수 있습니다. HUD 편집에는 보스 기믹 게이지를 추가합니다.

25수정사항

  • 아이템 장착창의 리스트형 슬롯과 상점 서버 이전 탭을 제거합니다. 필터를 끈 채팅의 미니 UI 활성화, 어비스 회랑 시간 만료 사망 퇴장의 부활 UI 누락을 고칩니다.
  • 몽층 II 변이된 울고른 피격 카메라, 아티엘 공격의 집중 막기·회피 판정, 업스케일러 설명, 상대 종족 주신의 모노리스 퀘스트 마커를 고칩니다.
