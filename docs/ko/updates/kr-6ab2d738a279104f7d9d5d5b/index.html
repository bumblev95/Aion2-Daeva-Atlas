02어비스

  • 재매칭으로 아티팩트·회랑 점령을 초기화합니다. 하층·중층에 대상 보스가 있으면 전장의 권능이 모든 플레이어에게 적용되고 보스가 없어지면 종료합니다. 균열 지대는 항상 적용합니다.
  • 대상 보스: 정령왕 아그로·감시자 카이라·차원핵·나흐마 2종·집행자 3종·처형관 드라모스·반역자 듀칼·파멸자 마라카입니다.
  • 이 버프는 노련한 반격·격앙·착취·불패의 진언·보호의 빛·질풍의 권능·대지의 축복을 대체합니다. 적용 중에는 그 효과를 중복 적용하지 않습니다.

03영혼 각인

  • 조율 시전 시간을 줄이고 자동 조율을 추가합니다. 옵션·재료를 등록해 목표 옵션 중 하나가 나오거나 재료가 떨어질 때까지 자동으로 조율합니다.

04상점

  • 아틀리에 의상·무기·날개·펫·감정 표현은 마우스 오버 미리보기를 제공합니다. 미리보기가 있으면 4열, 없으면 5열이며 품절·구매 불가 상품은 음영으로 구별합니다.

05옷장

  • 지원하는 무기 외형에 꾸미기 프리셋을 추가합니다. 상점·꾸미기에서 미리 볼 수 있고 적용에는 꾸미기 비용이 필요합니다.

06커스터마이징

  • 성별마다 프리셋 3종·헤어 9종·얼굴 2종·눈썹 1종을 추가합니다. 체형의 몸/머리 탭에 체구 항목을 추가합니다.

07시공의 균열 쟁탈전

  • 쟁탈전에도 전장의 권능을 적용합니다. 공격팀의 본 서버→이벤트 서버 재입장은 잠시 무적이며 활성 주둔지 근처로 도착하고 도착 지점 수도 늘립니다.
  • 방어 주둔지 피격 알림과 HUD 정보 버튼의 보상 미리보기를 추가합니다.

08UI 개선사항

  • 성역·초월 대기방과 패널에 난이도를 표시하고 월드맵·미니맵·투명맵의 잘못된 퀘스트 영역을 고칩니다.

19개선사항

  • 어비스 모든 지역·쟁탈전 모노리스와 경비병에 PVP 피해 증폭을 일부 반영합니다. 이에 맞춰 어비스 보스·차원핵 체력을 조금 늘립니다. 적용 비율은 공개되지 않았습니다.
  • 던전 실패 유지 시간 10→20초, 파티원 시야 범위 확대, UI 위 커서에서도 지면 타겟 스킬 발동과 채팅 스크롤 고정을 개선합니다.
  • 성역 칭찬 후보를 파티→포스로 늘립니다. 팝업을 오른쪽에 두고 많이 칭찬받은 플레이어부터 보여주며 칭찬 창이 있으면 마우스 포인터를 켭니다.
  • 아르카나 보유 상한 1,100개, 성역 포스 간 인원 이동을 지원합니다. 보스전·포스장 자리 이동은 제한됩니다. 백년삼 증표는 캐릭터·서버 창고에 넣을 수 있습니다.

20수정사항

  • 균열 지대 최소 기여도를 채우면 거리가 멀어도 보스 보상을 받습니다. 스트리머 이름 숨김은 미니맵 파티 리스트·정령성/치유성 소환체 피해 메시지·키스크 팝업에도 반영합니다.
  • 시즌 주간 포인트 게이지, 품절 티켓 교환 상품의 무료 가격 표시, HUD 주사위 버튼과 어비스 획득처 이동 시 지도 해상도 오류를 고칩니다.
  • 사망·기본 부활로 칭찬 창이 닫히거나 랭킹 정보의 칭찬 영역을 눌러 캐릭터 창이 닫히던 오류를 해결합니다.
  • 이스카리엘 결사의 수호를 전투구역 아래로 활강해 피하던 문제, 델트라스의 기본 부활 위치 공격 생성과 밧줄 사용 후 방향키 오류를 고칩니다.
  • 악몽 퇴장 후 자동 물약 슬롯의 잘못된 비활성 표시를 고치고, 영혼 각인 확률은 유효한 자릿수까지 표시합니다.

21회수 및 복구
