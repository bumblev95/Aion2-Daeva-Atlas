11월 4일 한국 패치

한국 어비스 아웃랜드의 모든 입장 시각이 10분 늦춰지고 시작 연출·독기·바람길·소모품 규칙이 조정됩니다. 표준 색상 코드, 봉혼석 연결 사용, 가을 패스가 추가되며 델트라스 충격 해제와 아웃랜드 화염 폭탄 피해 오류도 수정됩니다.

2026-11-03 UTC요약 검토 완료원문 수정: 2026-11-03 19:30 UTC
NC · 공식 원문 ↗

직업 변경과 주요 시스템 내용을 검토해 요약했습니다. 이벤트 보상·상품 전체 표는 공식 공지에서 확인하세요. 직업 표시는 공지된 변경을 분류합니다. 실전 영향은 효과를 설명한 분석이며 전체 DPS 실측 상승률이 아닙니다. 한 직업이 버프와 너프를 함께 받으면 ‘조정’으로 표시합니다.

    어비스 아웃랜드 · 입장 시간

    공지된 일일 입장 시간대가 모두 10분씩 늦춰지며 30분 간격 개설은 유지됩니다.

    변경 전11:00~13:30·20:00~23:30→변경 후11:10~13:40·20:10~23:40

    실전 영향 P0 해석: 기존 공개 초보 공략의 시간대로는 이미 사라진 회차를 기다릴 수 있어 즉시 수정해야 합니다. 신청 마감과 마지막 참가 가능 회차는 클라이언트 확인이 필요합니다.

  • ↔ 조정

    어비스 아웃랜드 · 시작·독기 페이즈

    경기 시작 뒤 장막 해제와 동시에 비공정이 사라지고, 상층 독기는 30초 늦게 등장하며, 중층 바람길 위치가 조정되고, 모든 층의 3단계 독기가 같은 피해량을 주도록 바뀝니다.

    실전 영향 P1 해석: 시작 위치 선정, 상층 타이밍, 중층 이동 경로와 후반 독기 생존 계획이 달라질 수 있습니다. 정확한 좌표·발동 시각·피해량·대응은 직접 검증해야 합니다.

  • ↔ 조정

    어비스 아웃랜드 · 은신·무적 물약

    은신 물약으로 숨은 상태에서 공격 스킬을 쓰면 은신이 해제됩니다. 무적 물약의 무적 지속시간은 줄지만 무적 중 이동과 스킬 사용이 가능해집니다.

    실전 영향 P1 해석: 은신 선공과 무적 이동 동선을 다시 시험해야 합니다. 무적 지속시간 전후 수치는 없어 가동률·피해 변화율을 임의로 만들지 않습니다.

  • • 기타 변경

    표준 색상 코드 입력

    커스터마이징·옷장·환경설정 > 채팅 글자 색상에 표준 색상 코드 입력란이 추가되며 기존 형식은 기존 색상 코드 입력란에서 계속 사용할 수 있습니다.

    실전 영향 P2 해석: UI·편의 변경입니다. 정확한 입력 예시를 게시하기 전 허용 형식·유효성 검사·프리셋 저장 동작을 확인해야 합니다.

  • • 기타 변경

    가을 출석·이벤트 패스

    11월 4일 점검 후부터 11월 11일 점검 전까지 7일 출석 보상이 추가됩니다. 10레벨 이상 캐릭터는 서버당 1회, 라인별 10만 키나의 이벤트 패스를 이용할 수 있으며 11월 11일 05:00까지 30레벨과 최대 10회 반복 보상이 제공됩니다.

    실전 영향 P1 해석: 임시 일일·성장 경로가 생깁니다. 미션 집계, 서버 구매 범위, 프리미엄 활성화, 보상 수령과 이벤트 재화 삭제를 확인해야 하며 전체 이벤트 표는 이번 highlights 검토 범위 밖입니다.

  • • 기타 변경

    봉혼석 연결 사용

    같은 등급 봉혼석을 연속 사용하는 자동 사용 기능이 추가되며 거래 불가, 거래 가능 순으로 소비합니다. 다른 등급으로는 자동 전환되지 않습니다.

    실전 영향 P2 해석: 초보 설정 안내에 공식 메뉴 경로를 추가할 수 있지만 인벤토리 소비 순서·설정 유지·중단 동작은 직접 검증해야 합니다.

  • ✓ 버그 수정

    델트라스 · 빙결 포박·충격 해제

    델트라스 전투에서 빙결 포박 대상이 특정 조건에서 충격 해제를 사용해 이동·스킬 사용이 가능하던 문제를 수정합니다.

    실전 영향 P1 해석: 한국 비탄의 설원 공략에서 충격 해제를 확정 탈출 수단으로 볼 수 없습니다. 정확한 조건·면역 상호작용·파티 구조 대응은 실전 재현이 필요합니다.

  • ✓ 버그 수정

    어비스 아웃랜드 · 화염 폭탄 피해

    어비스 아웃랜드에서 화염 폭탄 피해량이 잘못 적용되던 문제를 수정합니다.

    실전 영향 P1 해석: 수치가 공개되지 않은 피해 동작 수정입니다. 같은 조건의 전후 피해를 재현하기 전 버프·너프 비율을 부여하지 않습니다.

주요 시스템·이벤트 변경

01지역·발표일·시행일

  • 한국 서비스 기준 11월 3일 19:30 UTC에 게시됐고 11월 4일 정기점검으로 적용됩니다. 이번 검토는 공식 원문 해시 cebda46d…에 연결했습니다.
  • 한국 전용입니다. 아웃랜드 시간·보스 수정·이벤트 비용·설정을 북미에 복사하지 않습니다. 직업 계수·쿨타임·스킬 레벨 효과·실측 DPS 결과는 공지되지 않았습니다.

02아웃랜드 일정·전투 규칙

  • 공식 확인: 두 입장 시간대가 정확히 10분씩 늦춰져 11:10~13:40·20:10~23:40에 30분 간격으로 열립니다. P0 공개 경로는 /guides/abyss-outland/·/ko/guides/abyss-outland/, 소스는 outland.py입니다.
  • 공식 확인: 장막·비공정 타이밍, 상층 독기 지연, 중층 바람길 위치, 3단계 독기 피해, 은신 해제와 무적 동작이 바뀝니다. P1: 날짜가 있는 준비 공략에는 발표 사실을 반영하되 정확한 좌표·수치·전술은 미검증으로 유지합니다.

03보스·피해 수정

  • 델트라스의 공지된 빙결 포박·충격 해제 우회가 제거됩니다. P1 공개 경로는 /guides/kr-bitan/·/ko/guides/kr-bitan/, 소스는 advancedguides.py입니다. 발동 조건·상태이상 면역·스킬 사용 가능 여부·파티 구조 흐름을 게임에서 확인해야 합니다.
  • 화염 폭탄 피해는 전후 수치 없이 수정됩니다. data/skills.json·data/skill-snapshot.json·eDPS 입력·과거 순위는 유지합니다.

04성장·설정·기간 이벤트

  • 출석과 가을 패스는 한국의 기간제 성장 경로입니다. 검증 후 P1 경로는 /routines/·/endgame/과 한국어 대응 페이지, 소스는 routines.py·progression.py입니다. 상시 우선순위에 넣기 전 해금·미션 집계·비용·서버 범위·수령·만료를 확인해야 합니다.
  • 표준 색상 코드와 봉혼석 연결 사용은 /start/?view=settings·/ko/start/?view=settings 및 onboarding.py의 P2 설정 보강 대상입니다. 이번 패치 검토에는 정확한 메뉴·동작을 기록하며 UI 설정 유지와 입력 검증은 미확인입니다.

05검토 범위

  • 아웃랜드·보스 수정·성장 관련 시스템을 다룬 highlights 검토입니다. 이벤트 보상·상품 표 전체 재정리, 인게임 검증 완료나 최종 직업 티어를 주장하지 않습니다.
