주요 시스템·이벤트 변경

01계승석·레기온 UI

  • 장비 부위별 계승석을 유일/영웅 계승의 불꽃으로 통합합니다. 기존 계승석은 빛바랜 아이템으로 바뀌며 물질변환으로 새 재료를 얻습니다. 계승석 조각도 변환할 수 있습니다.
  • 레기온 목록에 접속 중인 던전 이름을 표시하고 아이템 레벨·전투력 정렬을 지원합니다.

02비탄의 설원 최초 토벌 보상

  • 최초 클리어 포스에는 타이틀과 황금빛 보이드, 2~5번째에는 은빛 보이드, 6~20번째에는 구릿빛 보이드를 우편 지급합니다. 우편 수령 기간은 1개월입니다.

03할로윈 출석·미션·상점

  • 10월 14일 점검 후부터 11월 4일 점검 전까지 진행합니다. 출석은 매일 00시 초기화하며 보통 35주화, 7·14일차는 각각 100주화를 줍니다.
  • 한국 이벤트 미션은 캐릭터당 주 1회입니다. 어비스·초월·원정·각성전·악몽은 각 25주화, 접속 3회는 30주화, 장비·주문서·차원 침공·슈고페스타는 각 20주화입니다.
  • 마을 상점에서 외형 흉갑은 15주화·서버당 1개, 오드 에너지는 10주화·서버당 4개·50레벨 조건입니다. 도전권·성장 재료·강화 소모품도 교환하며 전체 제한은 공식 표를 확인하세요.

04원정·초월 할로윈 부스트업

  • 지정된 원정 보통·어려움 및 초월 1~4단계의 오드 에너지 큐브 강화석 보상이 1.5배가 됩니다. 붉은 연심의 거울은 강화석 보상이 추가되는 항목입니다. 적용 던전은 공식 표를 확인하세요.
  • 캔디 열쇠 조각은 지정 던전·난이도에 따라 3개 또는 5개를 얻습니다. 색깔 열쇠는 100조각으로 만들며 색깔별 서버당 주 1회입니다. 북미의 60조각과 다릅니다.
  • 빨강 캔디에는 영혼 결정 10,000개, 노랑에는 강화석 30,000개, 파랑에는 오드 에너지 4개가 포함됩니다. 각 캔디에는 추가 성장 재료와 소모품도 들어 있습니다.

05보스·방어력·설정 수정

  • 방어력 스탯이 일정량 이상 증가하지 않던 문제를 수정합니다. 시련·성역 재도전 때 부활 횟수 초기화 실패도 수정합니다.
  • 어비스 카이라·아그로의 충돌 범위를 소폭 확대합니다. 아티엘 사망 뒤 남던 상태이상을 해제하고, 델트라스의 얼음 쐐기 체력을 기존 대비 50% 낮춥니다.
  • 카메라 Y축 반전과 자신의 네임 플레이트 항목별 숨기기를 추가합니다. 직접 클릭한 드랍은 획득 설정과 무관하게 주울 수 있고, 일반 소모품 설정은 일반 등급 이하에만 적용됩니다.
  • 응룡왕·기룡왕 각인 장비의 계승의 불꽃 변환 실패와 익스프레스권 사용 뒤 종족 이해도 업적 누락을 수정합니다.

06회수·복구와 외형 상품

  • 10월 7일 전 히든 큐브 사용 로그로 영혼 결정 보상 차액을 소급 지급하고 펫 종족 이해도 포인트에 반영합니다. 자동 줍기권 가격 변경 차액은 구매·판매·복구 이력으로 구분해 지급합니다.
  • 서버 이전 후 아직 접속하지 않은 캐릭터의 소급 보상은 추후 별도 지급됩니다. 새 방어구·무기·펫·날개·투구·장식 외형도 추가되며 전체 상품 표는 공식 원문에 있습니다.
