    불의 신전·사나운 뿔 소굴 · 난도 표시

    불의 신전과 사나운 뿔 소굴 원정에서 어려움 난도가 선택지로 잘못 표시되던 문제를 수정합니다.

    실전 영향 P1 해석: 제거된 선택지를 기준으로 입장·보상·성장 계획을 세우면 안 됩니다. 이용 가능 난도·UI 수정이며 일반 난도의 패턴이나 피해가 바뀌었다는 근거는 아닙니다.

    클라이언트 업데이트 필요

    핫픽스 적용을 위해 AION 2를 종료하고 Steam 또는 PURPLE 런처에서 업데이트한 뒤 게임을 다시 시작해야 합니다.

    실전 영향 P2 해석: 실행 중이던 클라이언트에는 업데이트·재시작 전까지 오래된 선택지가 남을 수 있습니다.
