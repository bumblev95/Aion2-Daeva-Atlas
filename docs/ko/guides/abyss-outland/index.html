무엇을 하는 콘텐츠인가요?

약 100명이 최후의 1인을 가릴 때까지 경쟁하는 개인 PvP 생존전입니다. 오래 살아남은 순서로 순위가 정해지므로, 공식 목표는 생존입니다. 던전 보스를 잡는 콘텐츠와는 다릅니다.

처음 참가하는 순서

  1. 두 가지 수치 확인

    캐릭터 45레벨 이상과 아이템 레벨 3,000 이상을 모두 확인하세요. 한 가지만 충족하면 안 됩니다. 아이템 레벨과 전투력은 다른 수치입니다.

  2. 참가 시간 고르기

    아래 한국 서버 일정에서 시간을 고르세요. 시간을 비워두기 전 현재 클라이언트 공지에서 점검·변경 여부를 확인하세요.

  3. 어비스 UI에서 입장 안내 확인

    공식 입장 경로는 어비스 UI입니다. 그 안에서 아웃랜드 입장 안내를 확인하세요. 정확한 탭·버튼명, 신청 시작 시각, 확인 절차는 미검증이므로 현재 화면 안내를 따르세요.

  4. 첫 판은 적응 목표로 준비

    편집자 준비 팁: 참가 전 익숙한 이동·방어 스킬의 조작을 점검하고 표시되는 경기 규칙을 읽으세요. 필수 장비·소모품·PvP 빌드나 승리 전술이 검증된 것은 아닙니다.

  5. 종료 후 순위·보상 확인

    결과와 실제 지급 주화를 확인한 뒤 남은 주간 획득 한도·교환 상점 가격을 확인하세요. 결과 화면 구성과 수동 수령·자동 지급 여부는 미검증입니다.

언제 참여하나요?

  • 11:00–13:30
  • 20:00–23:30

매일 공지된 두 시간대에 30분 간격으로 경기가 열립니다. 휴대폰 현지 시간이 아닌 한국 서버 기준입니다. 30분은 개설 간격이며 한 경기의 길이가 30분이라는 뜻은 아닙니다. 신청 마감과 마지막 회차 접수는 게임 내 확인이 필요합니다.

무엇을 받고 언제 초기화되나요?

생존 순위에 따라 방랑자의 주화를 얻고, 어비스 교환 상점에서 물품을 구매할 수 있습니다.

주간 획득 한도가 있으며 매주 수요일 05:00에 초기화됩니다. 초기화 대상은 획득 한도입니다. 보유 주화가 사라진다는 안내는 없습니다. 순위별 지급량·한도 수치·상점 가격·캐릭터/계정 적용 범위는 미검증입니다.

사용 전 실제 상점 가격과 보유 주화를 비교하세요. 확정 주간 수입이나 추천 구매 순서를 임의로 계산하지 않았습니다.

게임 내 검증이 필요한 항목

  • 매칭 방식·실제 참여 인원·경기 시간·동순위 처리
  • 화면 버튼·신청 마감·보상 수령 조작
  • 순위별 주화·주간 한도 수치·상점 품목/가격·한도 적용 범위

입장이 안 되면 두 참여 조건·현재 한국 서버 시간·표시된 제한 안내부터 다시 확인하세요. 숨겨진 선행 퀘스트나 특정 버튼 순서를 추정하지 마세요.
