열쇠·보상

언제 보상을 받을까?

순위 → 보상 선택 수

높은 순위일수록 선택 수가 늘며, 보상 수령에 열쇠를 씁니다.

연습 → 수령 판단

열쇠 없이도 참여할 수 있고, 큐브 선택을 포기하면 열쇠를 보존합니다.

서버 공유 열쇠 상한

공략 기준 상한은 기본 12·멤버십 21개입니다. 상한에서는 충전이 멈춥니다.

상점 사용

모은 토큰을 성장에 쓰기

  1. 교환 목표 하나 정하기우리의 선택 기준: 스킬·데바니온·수집 중 필요한 성장부터 정하세요.
  2. 구매 제한 읽기월간 한도와 초기화되지 않는 누적 한도를 구분합니다.
  3. 필요한 품목부터 구매글로벌 공략의 샤드 35개 비용은 토큰 10,500개입니다. 현재 상점 표기도 비교하세요.
