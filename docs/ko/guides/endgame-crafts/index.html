Abyssal Bracelet · 팔찌

글로벌 플레이 공략의 제작 재료: Ludra Gear Voucher (Bound) 3개 + 키나 5,000,000.

루드라 보상에서 교환권을 모으고 제작용으로 남깁니다.

아르카나

자주 쓰는 스킬을 위한 제작

기본 유일 아르카나 제작

글로벌 표의 기본 제작은 Mysterious Crystal 5개 + 키나 2,000,000. 추가 선택 옵션에는 비용이 더 듭니다.

필요한 카드부터 선택

성배·양피지·나침반·종·거울은 슬롯이 다릅니다. 제작 전에 필요한 스킬·패시브 보너스를 비교하세요.

재료 모으기

남길 것·모을 것·만들 것

  1. 완성품 하나 선택우리의 선택 기준: 보완할 부위나 주력 스킬을 먼저 정하세요.
  2. 쓸 카드는 먼저 남기기결정은 시즌 보상·아르카나 추출 경로를 확인합니다. 쓸 카드를 먼저 남기세요.
  3. 총 제작 비용 확인기본 제작과 추가 선택 비용을 구분하고 다음 성장에 쓸 키나도 남깁니다.
