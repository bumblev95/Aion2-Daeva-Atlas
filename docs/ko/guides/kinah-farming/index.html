무엇을 팔아 거래소 자금을 만들까?

해당 아이템이 거래 가능하고 실제 구매자가 있어야 판매 수입이 됩니다.

정복 던전 제작 재료

Wrathful Mind는 기본 6종, Wrathful Will은 우루구구·바크론 이상, Wrathful Ego는 불의 신전·사나운 뿔에서 노립니다. 용제 제작용 재료이며 남는 거래 가능분을 판매합니다.

기존 동선에서 채집

이동 동선의 광석·목재·오드 시세를 비교합니다. 직접 제작에 쓴 채집물은 구매 비용을 아끼는 것이고, 실제 판매가 성사된 것만 수입입니다.

제작은 재료값부터 계산

Ruby Powder·Yggdrasil Paper 같은 가공 재료는 원재료 그대로 판매할 때와 비교합니다. 구입 재료값과 화면에 표시되는 판매 수수료를 함께 계산하세요.

순수입 = 실제 판매대금 − 구매한 재료값 − 판매 비용

현재 서버 시세·시간당 수급량을 측정한 자료는 없습니다. 소량이 팔리는지 확인한 뒤 물량을 늘려 강화 예산까지 재고에 묶이지 않게 하세요.
