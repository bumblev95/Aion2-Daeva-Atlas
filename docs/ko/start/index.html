첫 캐릭터 육성의 핵심 4가지

메인 진행, 스킬 투자, 장비 판단, 던전 준비를 기준으로 정리했습니다. 필요한 항목에서 상세 공략으로 이어집니다.

01

메인 진행과 동선

메인 에피소드를 진행 축으로 잡고, 막힌 구간에서는 선행 조건부터 확인합니다.

이동 거점과 동선 근처 성장 콘텐츠를 함께 챙기는 방식입니다. 멀리 우회할 콘텐츠는 보상을 먼저 비교합니다.

다음 퀘스트가 막힌 이유를 확인하지 않은 채 사냥량만 늘리는 것은 비효율적입니다.

지도에서 위치 확인 →
02

스킬 투자 순서

주력 스킬과 발동 조건을 먼저 파악한 뒤 포인트 투자 순서를 정합니다.

직업별 빌드에서 우선 투자할 기술·패시브·스티그마를 함께 확인할 수 있습니다. 직접 투자한 포인트와 합계 스킬 레벨은 구분해야 합니다.

딜 사이클만 외우기보다 어떤 조건에서 기술이 연결되는지 알아야 실제 전투에 적용하기 쉽습니다.

직업별 스킬·투자 순서 →
03

장비 교체와 강화

같은 부위의 장비를 비교하고, 현재 필요한 옵션과 교체 계획을 기준으로 강화 여부를 판단합니다.

입장 조건을 맞추려는 것인지, 생존·명중·피해량을 보완하려는 것인지 먼저 구분합니다. 강화 비용은 해결하려는 문제와 함께 봐야 합니다.

장비 점수가 높다는 이유만으로 현재 세팅에 모든 옵션이 유효한 것은 아닙니다.

장비·스탯·강화 판단 →
04

첫 던전 준비

난이도·입장 조건·파티 모집 조건을 확인한 뒤, 전멸이나 큰 손실로 이어지는 패턴부터 파악합니다.

보스 공략은 전조가 무엇인지, 어디로 이동하는지, 내 역할이 무엇인지로 나눠 보면 핵심이 명확해집니다.

모집글의 전투력 수치는 해당 파티의 조건입니다. 모든 서버·난이도에 적용되는 권장 컷으로 해석하지 않습니다.

보스별 패턴·이동 위치 →

세팅할 때 혼동하기 쉬운 구분

캐릭터 레벨 / 스킬 레벨
캐릭터의 성장 단계와 개별 기술의 레벨은 다릅니다. 스킬 투자에는 해당 기술의 조건과 비용이 따로 적용됩니다.
아이템 레벨 / 유효 옵션
장비 수준·착용 조건·옵션의 효율은 별개입니다. 같은 부위와 목적의 장비끼리 비교해야 합니다.
스티그마 / 아르카나
스티그마는 스킬 세팅, 아르카나는 장비에 해당합니다. 아르카나 이름을 딜 사이클에 사용하는 기술과 혼동하지 않습니다.

편의 설정과 메뉴 위치

설정 위치·용도·실제 캡처를 함께 정리했습니다. 메뉴 경로는 연결된 한국 서버 원문 캡처 기준입니다.

01

보스 뒤쪽 찾기

설정 위치환경 설정 → 정보 출력 → 전투 → 보스 방향 마커 표시: BACK

BACK 표시는 보스의 뒤쪽 방향을 구분하는 기준입니다. 후방에 있다는 것과 해당 공격의 안전지대에 있다는 것은 별개입니다.

스크린샷 원본 크게 보기 ↗구원의노래 · Inven ↗
02

채팅이 언제 왔는지 보기

설정 위치채팅 설정 → 시간 표시: ON

파티 지시나 모집 메시지가 언제 올라왔는지 구분할 수 있습니다. 여러 메시지가 섞일 때 이전 안내와 현재 안내를 확인하기 편합니다.

스크린샷 원본 크게 보기 ↗구원의노래 · Inven ↗
03

자동 사용 조건 확인하기

설정 위치환경 설정 → 전투 → 자동 사용

물약의 생명력 기준과 버프의 전투 중 사용 조건은 별도 설정입니다. 캡처의 퍼센트를 정답으로 복사하기보다 사용하는 소모품과 상황에 맞춰 구분합니다.

추출 전에 목록 확인하기

설정 위치가방 → 추출 → 간편 선택 설정

간편 선택이 어떤 장비를 포함하는지 확인한 뒤 추출합니다. 보관할 장비가 섞이지 않는 기준을 정하기 전에는 자동 추출을 꺼두는 편이 안전합니다.
