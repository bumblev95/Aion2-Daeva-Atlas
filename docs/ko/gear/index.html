01 / READ YOUR LOOT

장비의 한 줄씩 눌러보세요.

설명용 예시 · 실제 드롭 장비·추천 세팅이 아닙니다

01 / 등급 / 색상

유일

등급은 분류입니다. 같은 부위·용도의 장비끼리 실제 효과를 비교하세요.

02 / 아이템 레벨

아이템 레벨 ≠ 캐릭터 레벨

아이템 레벨은 장비의 수준입니다. 착용 조건과 던전 입장 조건은 따로 확인하세요.

03 / 기본 능력치

무기 공격력 / 방어구 방어력

부위의 기본 기능부터 읽으세요. 그다음 지금 해결하려는 문제에 도움이 되는지 확인하세요.

04 / 추가 옵션

명중 · 치명타 · …

옵션을 하나씩 읽어보세요. 점수가 높다고 현재 세팅에 모두 유효한 옵션은 아닙니다.

05 / 강화 수치

+N

이 장비에 투자한 강화 단계입니다. 비용·성공률·교체 계획을 보고 투자하세요.

02 / SIX BASE STATS

익숙한 이름, 다른 역할.

MIGHT →

공격력

공격력을 높이는 기본 능력치입니다.

DEXTERITY →

회피 · 방패 방어 · 치명타 저항

방어 계열 능력치이며 궁성의 공격력으로 바로 해석하면 안 됩니다.

INTELLIGENCE →

상태 이상 적중

상태 이상이 적용될 가능성과 연결됩니다. 마법 공격력이 아닙니다.

CONSTITUTION →

최대 생명력

생명력의 기반입니다. 생존에는 피해 감소와 기믹 대응도 필요합니다.

PRECISION →

명중 · 치명타

공격의 명중과 치명타에 연결됩니다.

WILLPOWER →

상태 이상 저항

상태 이상 저항을 돕습니다. 모든 보스 기믹을 무시할 수 있다는 뜻은 아닙니다.

01

막힌 이유 확인

02

강화 화면 읽기

장비 종류·성공률·재료를 확인하세요. 일반 장비와 충돌 룬의 실패 규칙은 다릅니다.

03

중단선 정하기

누르기 전에 사용할 재화 한도를 정하고 강화 후 효과를 다시 확인하세요.

강화 실패 시 어떻게 되나요?

글로벌 참고 DB상 일반 무기·방어구·장신구는 실패 시 재료를 소모하며 강화 단계가 내려가지는 않습니다. 충돌 룬은 단계가 하락할 수 있는 예외입니다. 내 아이템의 확인창을 읽으세요.
