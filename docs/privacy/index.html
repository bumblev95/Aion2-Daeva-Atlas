Privacy & local data

What this release stores and how to delete your saved planner.

Effective October 7, 2026. This notice describes this release of PLAYER’S CODEX.

What the website stores

The planner saves task text and completion state in your browser’s local storage under daeva-atlas-planner-v1. A saved class preference uses raidnote-aion2-class-v1. Beginner checklist completion uses players-codex-start-v1. Temporary gear checks last only for the current visit. We do not upload these to a server. It persists until you clear it or clear browser storage, and it does not sync between devices. Avoid putting private account information in a task.

Hosting and external links

GitHub Pages delivers this website and may process request information such as IP addresses and access logs under GitHub’s own policies. When you follow a link to NC, Steam, GitHub or another website, that service handles your visit under its policies. Fonts are local or system resources. Boss preview screenshots load from Inven. Opening the maps page loads a The Hidden Gaming Lair map. Playing a video loads a YouTube privacy-enhanced embed; optional KR loops load from Inven. These services receive your network request and apply their own policies. YouTube playback may include platform advertising or storage.

GitHub General Privacy Statement ↗

Advertising and analytics

We do not install AdSense, Google Analytics or advertising trackers on this site. External map and video providers operate under their own policies. Before advertising or analytics is enabled, this notice must be updated to describe the services and choices actually offered. A generic cookie banner is not a substitute for the consent management required by an advertising provider.

Contact

For site or privacy questions, use the project issue tracker. GitHub issues are public; do not include passwords, account identifiers, payment details or other private information. A GitHub account is required to submit an issue.
