단죄는 낙인 2초/연쇄 3초의 새 준비 상태를 별도 합성 제공기로 연결했다. 오프너가 1초에 완료된다는 가정에서 첫 단죄 타격은 2초에 발생한다. 준비 상태 없음·과거 대상 디버프만 있음·공격 불가 동안 창 만료 시에는 발동하지 않는다. 창의 실제 생성 시점·소비·사용 횟수를 확정한 결과가 아니며, 보수적인 기본 쿨 3초와 동작 1초 때문에 두 창 모두 이 작은 예에서는 1회만 가능하다.

`elemental-fusion` −35%와 강림 중 +100%를 더해 +65%라고 단정하거나, 자동으로 0.65×2로 합성하지 않는다. 피해 그룹 합성·지연 피해의 시전/적중 판정 시점이 확인되기 전에는 결합 실험을 만들지 않았다. 심판의 최대 3회도 일반 쿨 3초만 줄인 로테이션으로 구현하지 않았다.

## 코드 변경과 보호 장치

- `resolveOfficial()`은 `research-only` 명시, `KR`, 정확한 적용 버전, 원문 해시, 스킬/필드가 모두 맞을 때 숫자 또는 표의 복사본만 반환한다. NA/Global·누락 필드·미래 패치에는 대체값을 제공하지 않는다.
- 기존 한국 오버라이드 17개 전체를 연구 입력과 비교하고 원문 리뷰의 해시도 대조한다. 출처·입력이 바뀌면 재검토 전 실패한다.
- 기존 글로벌 스킬·카탈로그·엔진·학습 모델/결과·랭킹 JSON/CSV 등 14개 입력의 SHA-256을 고정한다. 원래 코드 경로와 과거 결과에 쓰지 않는다. 이 해시는 해당 커밋의 재현 기준이므로 이후 입력이 바뀌면 이 연구를 재검토해야 한다. 전용 CI의 경로 제한으로 일반 뉴스·랭킹 갱신을 이 과거 연구에 묶지 않는다.
- 모든 기존 8직업의 테스트 시나리오에서 기본 로테이션 및 선택된 학습 정책을 전후 재생해 결과가 같은지 검사한다. 테스트는 신규 실험 실행 후 파일 바이트와 메모리 입력도 동일한지 확인한다.
- `--write`는 이 연구 폴더의 `results.json`만 쓴다. `--verify`는 재계산 결과와 저장 결과를 바이트 단위 비교한다. 결과에는 입력과 실험 코드 해시를 보존한다.
- 이 연구 폴더·전용 테스트의 PR 변경 때만 실행하는 별도 CI에 입력 회귀·결과 재현 검사를 추가한다. 기존 일반 검증 워크플로는 그대로 둔다. Pages 산출물·스킬 원본·스냅샷·글로벌 계산·역사 랭킹·기존 학습 결과는 변경하지 않는다.

## 실행 방법

저장소 루트, Node 22+ 및 Python 표준 라이브러리만 사용한다. 기본 회귀·재현 검사는 네트워크를 쓰지 않는다.

```sh
node tests/kr-patch-inputs.test.js
node research/kr-20261111/audit.js --verify
python -m unittest discover -s tests -p 'test_kr_patch_source.py'
```

실험 재생성은 `node research/kr-20261111/audit.js --write`. 기존 `research/rotation-learning/train.js`의 쓰기 모드를 실행하지 않는다. 공식 원문을 다시 확인하려면 아래 중 하나를 명시적으로 실행한다. 본문이 달라졌으면 자동 수용하지 않고 실패한다.

```sh
python research/kr-20261111/verify_source.py --fetch
python research/kr-20261111/verify_source.py --file /path/to/nc-api-response.json
```

## 검증 결과와 남은 작업

로컬 확인: 사이트 빌드/링크·JSON 검증 통과, 생성된 `docs/` 차이 없음. 기존 Python 테스트와 DPS·피해 수학·역사 랭킹 재현·로테이션 연구 재현·패치·분석·전투 테스트 통과. 신규 지역/버전/해시·상태 창·자원·비변경 검사 통과. UI를 바꾸지 않았으므로 이번 변경을 위한 브라우저 조작 검사는 별도로 수행하지 않았다. CI 결과는 PR에서 별도로 확인해야 한다.

다음 실측은 동일 KR 패치·동일 스킬 레벨/특화/장비/파티 조건으로 오프너→조건기 타격 시각, 충전/초기화 순서, 자원 수지, 정령 틱·원소·강림·지연 피해를 녹화/로그로 확보하는 것이다. 권성은 먼저 원본 스킬 카탈로그가 필요하다. 이후에만 전용 KR 카탈로그와 검증된 전투 재생을 만들 수 있다.

연구 분기에서 검토하며 **병합·공개 배포는 소유자 승인 전 수행하지 않는다**. CI 성공은 계산 재현성과 기존 동작 보존을 뜻하며, 라이브 한국 DPS 정확도나 최종 티어를 입증하지 않는다.
